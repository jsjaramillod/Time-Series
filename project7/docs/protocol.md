# Six-month payroll evaluation protocol

The question comes from the final discussion of doctoral assignment 7. What happens if the interpolation benchmark and the volatility model both predict the same six months? This protocol fixes the comparisons before scoring.

- Begin each fit in January 1962 and include twelve monthly lags and an intercept. Use the full five-variable information set from Project 06 in coursework units (log levels multiplied by 100, spread in percentage points). Use a common observed-history prior calibration at each origin.
- Fit three treatments: observed inputs with constant covariance, interpolated training inputs with constant covariance, and observed inputs with temporary covariance scaling. Match the interpolation convention in Project 06. Remove December 2019 through January 2022 from the raw levels and interpolate in elapsed time between November 2019 and February 2022. The volatility window instead runs from March 2020 through March 2022 inclusive.
- Start all three forecasts from the observed twelve-month state at each origin. Also calculate an interpolation sensitivity initialized on its own smoothed lags. This separates a change to parameter estimates from replacing already observed information at issuance.
- The monthly origins run from March 2022, when the volatility window is complete, through June 2024, the latest six-month origin with a full sequence of historical first-release changes in Project 06's contiguous 2007–2024 evaluation. The last target is December 2024. Use only observations through the origin and its recorded release date. The estimation inputs are revised, so the exercise is pseudo-real-time.
- Score cumulative changes in observed payroll levels, in thousands, on the frozen workbook. As a sensitivity, sum the six initial monthly changes in the BLS revisions table. This latter total spans six release vintages. Report root mean squared error (RMSE) of the predictive mean, mean absolute error, central 90% interval coverage, width and interval score. Lower interval score rewards narrow intervals while charging twenty times the shortfall outside a 90% interval. Show all six nonoverlapping origin offsets.
- Score the March–September 2026 illustration separately using the difference between the two seasonally adjusted levels in BLS's September release vintage. The issue date for the March panel is April 16, 2026. Neither the date the coursework forecast was computed nor its exact input vintage is established. Preserve the original saved log-growth percentiles as the direct point of comparison.
- A separate scenario holds the February 2020 observed state and post-crisis parameter draws fixed, switching only future variance scaling on and off. It uses information learned after the crisis, and is excluded from historical accuracy measures.
- The Gaussian signal exercise uses the supplied 200 messages, the stationary prior and known parameters. Independently check the terminal filtered result against conditioning on the joint Gaussian vector of all messages.

A supplementary point benchmark was added after the three models had been scored. It repeats the job gain of the six months immediately preceding each origin. It uses the same revised input snapshot, dates and outcomes. Its rule has no fitted parameters or probability intervals. The forecast records include both input levels.
