# Evaluation protocol

The four exercises correspond to the author's doctoral Problem Sets 9–10. Each uses a separate dataset. The only out-of-sample prediction comparison is on the indexed wide panel.

1. Reconstruct the saved 400-draw macro factor calculation with its seed, column order, preprocessing and persistence update. Check the four loading means and persistence against the archived output. Refit with named series, reassign the eight special income observations to income, and include the stationary initial-state density in the persistence update. Hold the 25-month pandemic replacement fixed for this comparison. Also retain all monthly observations in an unadjusted sensitivity.
2. Revisit the four-fund application with daily USD adjusted closes. Use the common trading dates from January 2010 through May 2026, retaining the preceding December close for the first return. Fix the positive loading on SPY. Assess co-movement and persistence retrospectively. The submission gives plots and names the four ETFs, but does not establish the original price vintage or exact trading dates.
3. Re-estimate the three coursework forecast methods and an AR(4) benchmark on targets 301–400. Lag all regressors. Refit transformations and PCA loadings inside each origin. Before scoring those 100 observations, select one specification using expanding-window squared errors for targets 201–300. Candidates are centered PCA with 0, 1, 2, 4, 8 or 16 components and ridge penalties 1, 5, 15, 50, 150, 500, 1500 and 5000. Zero components denotes AR(4). Freeze the winner's specification at origin 300. Retain per-origin forecasts and report both halves of the evaluation.
4. Fit a two-variable Bayesian VAR with four lags to log changes in productivity and hours, ending 1994Q3 and 2019Q4. Use the same prior formula and require four observed growth lags. Release the eligible-draw fraction and the cumulative response of hours for quarters 1–12 (quarter 1 is impact). Technology is the shock with a permanent productivity effect of positive sign. Repeat both samples with half the coefficient-prior standard deviation. These are conditional responses. The exercise has no observed structural shock against which to score accuracy.

The ridge comparison also audits units. With the same penalty of 15, fitting unscaled slopes recovers the submitted ridge score to three decimals. This is a numerical reconstruction because the submitted forecast code and individual class predictions are unavailable. A paired moving-block bootstrap resamples the two-component and selected-method forecast errors together, with lengths five and ten and 5,000 replications. It describes the uncertainty in the score difference conditional on the observed models and evaluation window.
